Your devices

Each paired phone holds the keys that let it open a verification document with no network. Pairing, re-keying and syncing are all done by scanning a code from this page: the code carries only this server's address and a one-time password, and the phone fetches everything else over an encrypted connection. What a phone may read follows you, not the handset: {% if restricted_tier %} your phones can see the holder's details. {% else %} your phones confirm a document is genuine but cannot read the holder's details. A site administrator changes that. {% endif %}
